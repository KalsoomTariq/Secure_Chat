### Description
A secure client-server chat application built with python and Flask

### Prerequisites
Make sure that you have Python 3 Installed in your system
### Setup Steps

1. Create a virtual environment
`python3 -m venv secure_chat_env`

2. Activate the virtual environment
`source secure_chat_env/bin/activate`

3. Install the dependencies
`pip install -r requirements.txt`

4. Create a 'creds.csv' file.

5. Run server using command
`python server.py`

5. Run client using command, where port can be specified
`python client.py [port]`
